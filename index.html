Calculation rules & data source
  • One export per day and environment. The environment is part of the file name, before the date: VMMHostExport_PROD_YYYYMMDD.csv, VMMHostExport_TEST_YYYYMMDD.csv.
  • All physical cores of a host are counted (PhysicalCPUCount × CoresPerCPU); hyper-threading is not counted.
  • Windows Server minimum licensing: 8 cores per processor, 16 cores per server, in 2‑core packs.
  • Monthly value per host = peak across all daily exports of the month. A host counts as soon as it appears on any day.
  • Total = sum of all environments (PROD + TEST). The breakdown by environment and edition is shown for verification.
  • Edition is taken from OperatingSystem (Datacenter / Standard); the last day of the month is decisive.
  • Data source: the report/ subfolder. Loaded automatically on startup via the web server's directory listing or the folder remembered by the browser (Edge/Chrome), otherwise via “Choose folder” or drag & drop.

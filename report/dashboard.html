Berechnungsregeln & geladene Dateien
  • Pro Host werden alle physischen Cores gezählt (PhysicalCPUCount × CoresPerCPU); Hyperthreading (LogicalCPUCount) zählt nicht.
  • Mindestlizenzierung Windows Server: 8 Cores pro Prozessor, 16 Cores pro Server. Lizenziert wird in 2‑Core‑Packs.
  • Monatswert pro Host = Höchststand (Peak) aller Tages-Exporte im Monat. Ein Host zählt, sobald er an einem Tag im Monat auftaucht.
  • Edition wird aus OperatingSystem gelesen (Datacenter / Standard), massgebend ist der letzte Tag im Monat.
  • Das Datum wird aus dem Dateinamen gelesen (…_JJJJMMTT.csv). Mehrere Dateien am selben Tag: die letzte gewinnt.

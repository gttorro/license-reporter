Berechnungsregeln & Datenquelle
  • Pro Host zählen alle physischen Cores (PhysicalCPUCount × CoresPerCPU); Hyperthreading zählt nicht.
  • Mindestlizenzierung Windows Server: 8 Cores pro Prozessor, 16 Cores pro Server, in 2‑Core‑Packs.
  • Monatswert pro Host = Höchststand aller Tages-Exporte im Monat. Ein Host zählt, sobald er an einem Tag auftaucht.
  • Edition aus OperatingSystem (Datacenter / Standard), massgebend ist der letzte Tag im Monat.
  • Datum aus dem Dateinamen (…_JJJJMMTT.csv). Mehrere Dateien am selben Tag: die letzte gewinnt.
  • Datenquelle: der Ordner mit den CSV-Exporten. Beim Start automatisch über die Verzeichnisliste des Webservers oder den im Browser gemerkten Ordner (Edge/Chrome), sonst über „Ordner wählen“ oder Drag & Drop.
